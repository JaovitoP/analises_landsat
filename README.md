#### **2. Setup**

```bash

python -m venv venv

# Ativar ambiente no Windows (PowerShell)
.venv\Scripts\Activate.ps1

pip install -r requirements.txt

streamlit run streamlit_app.py # A aplicação abrirá no endereço http://localhost:8501
```
